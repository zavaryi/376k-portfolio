# 🌐 376K.XYZ Portfolio

An ultra-modern, cyber-minimalist portfolio website engineered for **[376k.xyz](https://376k.xyz)**.

## ✨ Features
- **Design System**: Dark glassmorphic theme with HSL palette, glowing border animations, and ambient cursor lighting.
- **Interactive Terminal Sandbox**: Embedded CLI in the browser with commands (`help`, `about`, `skills`, `projects`, `contact`, `whoami`, `uptime`, `socials`, `clear`).
- **Interactive Projects Filter**: Dynamic category filtering for Web, Systems, and Cloud engineering work.
- **Fast Edge CDN**: Deployed globally via Cloudflare Pages with custom security headers and DNS routing for `376k.xyz`.
- **Responsive**: 100% mobile, tablet, and desktop optimized.

## 🚀 Local Development
```bash
# Preview locally
npx serve .
```

## ⛅ Cloudflare Deployment
```bash
# Direct deploy via Wrangler CLI
npx wrangler pages deploy . --project-name=portfolio-376k
```
